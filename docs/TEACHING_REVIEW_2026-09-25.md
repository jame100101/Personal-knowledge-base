# 教学扩写与知识校正记录（2026-09-25）

本轮针对“概念没有讲清、教程过于概述”的反馈，先补齐从网页基础到框架的学习路径，再检查其他模块中的概念边界、代码反例和示例与章节的相关性。发布基线为 `9499503ad47c62c2b760f4314f578504138d277e`。

## 前端教学怎样改变

前端从 25 篇、43,507 字符扩展到 31 篇、90,215 字符（包含代码和 Markdown 标记，不能等同于纯中文篇幅）。新增“从网页基础开始”六课：

1. HTML、CSS、JavaScript、Vue、React 分别是什么，彼此怎样配合。
2. 从完整 HTML 文件学习文档、语义、链接、表单和 DOM。
3. 从可修改的样式学习选择器、级联、盒模型、Flex、Grid 和响应式布局。
4. 用原生 JavaScript 写文章搜索，逐步解释数据、事件与 DOM 更新。
5. 从安装、入口文件、单文件组件到完整 Vue 页面。
6. 从安装、JSX、组件、状态到完整 React 页面。

三种搜索实现采用相同数据和验收行为，并把文章中的代码直接作为可运行示例保存。每课解释运行位置、预期结果、常见错误及练习答案。原有 25 篇另补具体流程、决策理由或边界实验，继续覆盖组件、状态、路由、缓存、渲染、测试、安全与交付。

## 已校正的重要问题

| 模块 | 原问题或容易误读处 | 校正 |
| --- | --- | --- |
| TypeScript | 泛型 JSON 格式化承诺 string，但 stringify 可能返回 undefined | 明确回退文本和仍可能抛异常的输入 |
| TypeScript | 取首项函数允许空数组却断言一定有值 | 非空元组约束，反例编译检查 |
| TypeScript | 事件名泛型为联合时可能与 payload 失去关联 | 使用关联元组联合，拒绝不匹配调用 |
| TypeScript | 空字符串被 Number 转为 0、账户金额溢出 | 显式输入语法与安全整数边界 |
| TypeScript | 读取响应体断流被归为格式错误 | 分离读取与解析，覆盖网络、取消、HTTP、数据错误 |
| TypeScript / 跨语言 | 类型别名被误解为精确封闭对象、Optional.of 接收 null、C++ 返回临时实参引用 | 补足结构兼容边界，使用 ofNullable，改为值返回 |
| Java | Java 21 与 25 构造器规则混用、宽化转换遗漏精度损失 | 标明版本与具体数值转换 |
| Java | 泛型数组及 instanceof 表述过于绝对 | 区分可具体化类型与可静态证明安全的情形 |
| Java | 多篇用同一集合复制示例讲不相关主题 | 改为账户、多态、金额、过滤链、REST 错误、Kafka 提交、JFR、作品集和部署验收 |
| Java | Supplier 与 IOException 受检异常不匹配 | 使用 Callable，说明外围异常与重试前提 |
| Java | JDBC 无条件扣减、回滚异常覆盖原异常 | 条件更新、正金额校验、保留 suppressed exception |
| Java | future.get 超时被误当整体 deadline、文件真实路径检查被误当完整安全保证 | 明确任务取消、close 等待、路径竞态与原子移动边界 |
| Agent | 最小循环只回填工具结果，遗漏发起调用的 assistant 消息 | 修正消息顺序，说明伪代码和执行器职责 |
| Agent | 历史持久化暗示副作用恰好一次 | 解释动作成功与检查点提交之间的崩溃窗口 |
| Agent | 比较 hash 再 rename 被说成原子 CAS；Rust 固定临时文件名 | 补写者协调条件，采用独占临时文件，限制清理到自己创建的文件 |
| 后端 | Python 类型提示被当作整数校验，重试参数允许 NaN | 运行时输入校验及反例 |
| 后端 | 事务隔离只给结论 | 增加双会话实验、PostgreSQL RR 与序列回滚边界 |

## 发布方式

更新脚本逐篇对照发布基线，遇到远端额外编辑停止；写前保存原文备份，更新时核对 `updated_at`，保持文档 ID、标题、链接、目录与排序。新增六篇由追加脚本导入。发布后再次读取数据库比对正文，并在正式域名检查目录、正文目录导航及图表渲染。

这是一份可追踪的审查与测试记录，不作“全部历史内容已逐句复核”或“整个知识库永久零错误”的保证。后续发现问题应保留复现与来源，再追加修正。
