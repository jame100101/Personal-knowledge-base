# 中文教学表达调整（2026-11-01）

本轮先比较 GitHub 上三份中文 humanizer 项目，再把适合技术教程的规则放进知识库的编辑流程。扫描全部 314 篇课程，实际调整 84 篇：Agent 20 篇、Java 64 篇；另 230 篇保持原样。

84 篇并非全文重写。其中 47 段重新组织了表达，主要处理 Agent 循环、上下文、工具执行、Spring 和测试章节中的密集术语与压缩句；另清理 Java 文章里 240 处重复的“这里容易混淆的是”起句，后面的知识与限制仍保留。

## 已落地的内容

[中文教学写作约定](WRITING_GUIDE_ZH.md) 说明本项目的文体、事实保护要求和发布流程，含实际改写前后对照。根目录 `AGENTS.md` 将该约定纳入后续内容编辑工作。

[编辑工具](../tools/humanizer/README.md) 提供三条命令：

```bash
npm run content:style
npm run content:style:verify -- --base d1a96b5f762103b86cb48c06e5e4cf8def6db2ab
npm run test:humanizer
```

第一条只输出编辑线索，第二条比较改写前后的受保护内容，第三条验证工具自身。它们不自动改写，不向外部模型传输正文，不在读者打开页面时生成新内容。

## 发布

[发布清单](../scripts/humanizer-2026-11-01-manifest.json) 固定本轮 84 篇文档 ID、正文哈希和 Git 基线。发布前只读比对确认 84 篇待更新、230 篇一致，没有远端冲突；已保存全部公开文章的本地快照。发布时按 ID、旧正文摘要和更新时间检查并发编辑，只更新正文及其派生元数据，保留文章路径、归属和排序。
