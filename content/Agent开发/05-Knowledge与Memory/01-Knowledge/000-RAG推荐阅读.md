# RAG 推荐阅读

做一个会引用资料的问答程序时，先准备少量可核对的文档，再逐步加入检索与重排。每次回答都回到原文检查依据。下面的资料分别帮助理解检索过程与回答质量，不把找到相似片段等同于回答正确。

- [RAG 原始论文](https://arxiv.org/abs/2005.11401)：理解参数记忆与外部非参数记忆结合的出发点。
- [LlamaIndex RAG](https://docs.llamaindex.ai/en/stable/understanding/rag/)：数据摄取、索引、查询与 Agent 组合。
- [LangChain Retrieval](https://docs.langchain.com/oss/python/langchain/retrieval)：retriever、vector store 和 RAG 架构。
- [OpenAI Embeddings](https://platform.openai.com/docs/guides/embeddings)：向量表示、相似度与应用实践。
- [RAGFlow](https://github.com/infiniflow/ragflow)：适合研究文档解析、切分、检索与 grounded answer 的完整产品链路。
- [Stanford STORM](https://github.com/stanford-oval/storm)：研究多视角检索、提纲和带引用长文生成。
- [GPT Researcher](https://github.com/assafelovic/gpt-researcher)：观察搜索、抓取、筛选、引用和报告生成。

建议产出：一个资料研究助手，输入主题后生成问题清单，多轮检索，并输出每个关键陈述的证据 ID。
