# Coding Agent 源码研究模板与证据等级

读源码时，最容易把“看起来应该这样”写成“它一定这样”。这份记录方式把代码直接支持的事实、架构推断和未验证项分开。先固定版本，再沿调用关系找依据，读者才有机会重复你的检查。

> **版本与资料依据**
> - `last_verified`: `2026-08-24`
> - `version_scope`: `repository snapshots verified 2026-08-24`
> - `source_type`: `official-repository`
> - `stability`: `fast-moving`

先记录项目、版本、研究日期与覆盖范围，再沿一次任务查看循环、上下文、工具、权限和会话。如果项目还包含压缩、计划、子 Agent、Skills 或 MCP，分别说明它们从哪里接入。最后补充交互入口、持久化、运行观察与安全机制，避免只看到主循环就结束。

- **CONFIRMED**：固定 commit 的代码、测试或官方文档直接支持；给出文件/符号链接。
- **INFERRED**：由调用关系、依赖或目录结构推断；说明推理链和可证伪条件。
- **UNKNOWN**：静态材料未覆盖、需要运行/私有服务/产品行为验证。

研究快照与当前 HEAD 分开记录。更新 HEAD 不自动让旧结论失效，但必须重新核对变更范围后才可更新 `last_verified`。
